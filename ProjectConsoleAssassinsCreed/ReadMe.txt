게임 : 2D 어쌔신 크리드 
게임 목표 : 맵 내에 생성된 T or C를 사살하는 것
게임 설명 
초록색은 P, Player를 나타냅니다. 플레이어는 방향키로 움직이며, wasd로 바라보는 방향을 설정할 수 있습니다.
주황색은 G, Guard를 나타냅니다. 경비는 바라보는 방향에 일정 범위와 제한된 시야 각도로 플레이어를 탐색하며 플레이어를 발견 시 추적, 공격합니다.
파란색은 A, Archer를 나타냅니다. 궁수는 경비와 같은 탐색 로직을 가집니다. 플레이어를 발견할 시 공격합니다. 그러나 플레이어의 위치가 아주 가깝다면 플레이어의 반대 방향으로 도망갑니다. 

T는 타겟입니다. 스토리 상 의뢰인의 암살 대상입니다.
C는 의뢰인입니다. 스토리상 암살 의뢰를 맡긴 대상입니다.

방향키로 이동합니다.
wasd로 플레이어가 바라보는 방향을 설정할 수 있습니다. 카메라가 플레이어의 시야를 중심으로 이동합니다. 
스페이스바를 누르면 공격합니다. 공격 시 선/후 딜레이가 존재하며 해당 시간 동안 이동이 불가합니다.
컨트롤을 누르면 이동 속도가 일시적으로 증가합니다. 

게임 종료시 Restart Game이 출력된다면 엔터를 누를 시 초기화됩니다.
그렇지 않다면 프로그램 실행을 멈추고 visual studio에서 다시 실행하시기 바랍니다.
